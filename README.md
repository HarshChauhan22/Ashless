# Ashless

An India-first Android app to help smokers quit. When a craving hits, Ashless's "Digital Smoking Room" lets you redirect the money you'd have spent on a cigarette into a savings wallet instead — turning every avoided smoke into tracked, visible progress.

This repo contains the mobile app (`mobile/`, Expo/React Native), the backend API (`backend/`, NestJS + Postgres), an earlier web prototype (`webapp/`), and supporting product/design docs.
